\chapter*{Résumé}
\addcontentsline{toc}{chapter}{Résumé}
\thispagestyle{fancy}

\begin{mdframed}[linecolor=emsiRed, linewidth=1.5pt, backgroundcolor=emsiGray, innertopmargin=12pt, innerbottommargin=12pt, innerleftmargin=15pt, innerrightmargin=15pt]
La multiplication des projets logiciels dans les organisations modernes engendre des défis
croissants en matière de coordination, de suivi et d'affectation des ressources humaines.
Ce rapport présente la conception et le développement de \textbf{PT\_BACK}, une application back-end
RESTful développée avec le framework \textbf{Laravel} (PHP), visant à centraliser et à automatiser
la gestion de projets collaboratifs.

\vspace{0.4cm}

La solution proposée repose sur une architecture multi-rôles structurée autour de trois acteurs
principaux : le \textit{Manager}, le \textit{Chef de Projet} et le \textit{Développeur}. Le système
permet la gestion complète du cycle de vie d'un projet, depuis sa création jusqu'à la validation
des tâches, en intégrant des mécanismes de gestion des accords de niveau de service (\textbf{SLA}),
de suivi statistique et d'export des données.

\vspace{0.4cm}

La sécurité des accès est assurée par une intégration avec \textbf{Keycloak}, une solution open-source
de gestion des identités, garantissant une authentification centralisée par \textit{tokens JWT}.
L'application expose une API REST complète, documentée et sécurisée, constituant ainsi un socle
technique robuste sur lequel peut s'appuyer n'importe quel client front-end.
\end{mdframed}

\vspace{0.5cm}
\noindent\textbf{Mots-clés :} Laravel, API REST, Keycloak, JWT, Gestion de projets, SLA, PHP, MySQL, Multi-rôles.

\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}
\thispagestyle{fancy}

\begin{mdframed}[linecolor=emsiRed, linewidth=1.5pt, backgroundcolor=emsiGray, innertopmargin=12pt, innerbottommargin=12pt, innerleftmargin=15pt, innerrightmargin=15pt]
The growing number of software projects in modern organisations creates increasing challenges
in terms of coordination, tracking, and human resource allocation. This report presents
the design and development of \textbf{PT\_BACK}, a RESTful back-end application built with
the \textbf{Laravel} (PHP) framework, aimed at centralising and automating collaborative
project management.

\vspace{0.4cm}

The proposed solution is based on a multi-role architecture structured around three main actors:
the \textit{Manager}, the \textit{Project Leader (Chef de Projet)}, and the \textit{Developer}.
The system supports the complete project lifecycle, from project creation to task validation,
while integrating Service Level Agreement (\textbf{SLA}) management, statistical tracking,
and data export capabilities.

\vspace{0.4cm}

Access security is ensured through integration with \textbf{Keycloak}, an open-source identity
and access management solution, providing centralised \textit{JWT-based authentication}.
The application exposes a complete, well-documented, and secured REST API, forming
a robust technical foundation on which any front-end client can rely.
\end{mdframed}

\vspace{0.5cm}
\noindent\textbf{Keywords:} Laravel, REST API, Keycloak, JWT, Project Management, SLA, PHP, MySQL, Multi-role.
